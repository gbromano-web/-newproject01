# Manookan Fried Chicken House website

Static website for Manookan Fried Chicken House, 102 Gorordo Ave., Kamputhaw, Cebu City.
Hosted with GitHub Pages.

## What's where
- `index.html` — home page (menu, process, FAQ, story, visit)
- `blog/` — blog list and articles (one folder per article)
- `about/`, `contact/`, `privacy-policy/`, `terms/` — site information and legal pages
- `img/` — photos and logo
- `downloads/` — the PDF menu brochure
- `assets/page.css` — styles for the blog and info pages
